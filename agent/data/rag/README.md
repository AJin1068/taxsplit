# 근거 검색 원문 (`agent/data/rag/`)

근거 검색(작업 목록 PR 13, RAG)이 찾아 오는 **원문**이다. 계산 결과에 쓴 규칙마다 "어느 문서 몇 쪽에 그렇게 적혀 있나"를 이 파일에서 찾는다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `nts-2025-booklet.jsonl` | 국세청 「2025년 원천징수의무자를 위한 연말정산 신고안내」(2025.12 발간) 69쪽. 한 줄에 한 쪽 |

줄 모양:

```json
{"id": "nts2025-booklet-p173", "tax_year": 2025, "source": "2025년 원천징수의무자를 위한 연말정산 신고안내",
 "page": "p173", "print_page": 173, "pdf_page": 191, "text": "다. 의료비 세액공제(소법 §59의4 ②) ..."}
```

- `page`: 규칙표(`agent/src/taxsplit/rules/rules_2025.toml`)의 `pages` 칸과 같은 표기. 인쇄 쪽은 `p173`, 쪽 번호가 없는 앞쪽 요약은 `PDF 8쪽`.
- `pdf_page` = `print_page` + 18.
- `tax_year`: 귀속연도. 검색할 때 이 값으로 걸러 다른 연도 글이 섞이지 않게 한다(CLAUDE.md 설계 원칙 3).

## 넣은 쪽

| 부분 | 쪽 |
| --- | --- |
| 앞쪽 요약(세액계산 흐름, 공제 요건표, 과다공제 유형) | PDF 3~11쪽 |
| 외국인 과세특례(기본세율 조문 근거) ~ 근로소득공제·인적공제·연금보험료·보험료공제 | 인쇄 92~107쪽 |
| 신용카드 등 사용금액 소득공제 | 인쇄 132~139쪽 |
| 소득공제 종합한도 | 인쇄 147쪽 |
| 근로소득·자녀·의료비·교육비 세액공제 | 인쇄 162~186쪽 |
| 종합사례 | 인쇄 212~219쪽 |
| 끝수 처리(서식 작성방법 15) | 인쇄 242쪽 |
| 부록 4 맞벌이 부부 연말정산 | 인쇄 389쪽 |

규칙표 `pages`에 나오는 쪽 29개가 모두 들어 있다. 주변 쪽은 "비슷하지만 답이 아닌 쪽" 역할을 한다.

## 뽑은 방법

`pdftotext -layout`(poppler)로 쪽마다 글자를 뽑고, 모든 쪽에 찍힌 머리말 두 줄("원천징수의무자를 위한", "2025년 연말정산 신고안내")과 맨 아래 쪽 번호 줄만 지웠다. 원문을 고치거나 요약하지 않았다. 표는 글자 배치가 흐트러질 수 있다(예: PDF 8쪽 요건표).

## 쓰는 규칙

- 처리 코드는 이 파일을 **검색 대상**으로만 읽는다.
- 규칙표의 `pages`는 적중률 채점(정답)에만 쓴다. 검색 코드가 규칙 ID → 쪽 표를 만들어 바로 찾아가면 적중률이 의미 없어진다.
- 이 파일은 기획(Claude 앱)이 원본 PDF에서 만든다. 원본 PDF가 레포 밖에 있어 개발 세션은 다시 만들 수 없다. 쪽을 더하거나 다른 연도 문서를 넣을 때도 기획이 Issue로 낸다.
- 공개 레포에 넣는 근거: 국가가 업무상 작성해 공표한 저작물은 허락 없이 이용할 수 있다(저작권법 제24조의2). 출처는 각 줄의 `source`에 적었다.
